📘 신규 예약시스템, 운영자 입장에서 뭐가 달라지나요?

이번에 예약시스템이 새로 바뀌어요. 운영팀·영업실 입장에서 매일 보는 화면과 작업이 어떻게 편해지는지 사례 중심으로 정리했어요.

👉 한 줄로 말하면, 예약 1건마다 "가계부"가 생긴다고 생각하세요.
지금까지는 "통장 잔액"만 봤다면, 이제는 "언제, 누가, 왜, 얼마"가 줄줄이 적힌 가계부를 펼쳐볼 수 있어요.
이 가계부를 우리는 "예약 원장"이라고 불러요.

1 지금 운영하면서 불편했던 거, 이렇게 바뀌어요

사례 ① — "결제를 두 명이 나눠서 했어요" (카드 한도 초과)
👤 고객 김여행님 (예약자)
"제 카드 한도가 부족해서 150만원만 제 카드로, 나머지 139만원은 남편 카드로 결제할게요."
📕 지금 (불편함) 예약 한 건을 두 개로 쪼개서 만들어요.
→ 예약A 150만원 + 예약B 139만원
· 출발자명단·여행자 정보 따로 관리
· 정산도 두 번 처리
· 고객은 "왜 내 예약이 두 개야?" 혼란
→
📗 앞으로 (편리) 예약 한 건 그대로 두고 결제 링크만 두 개 보내요.
→ 예약자 150만원 결제 + 남편 139만원 결제
· 가계부에 결제 기록 2줄로 남음
· 여행자 정보 그대로
· 정산도 한 예약 안에서 자동
사례 ② — "결제수단 바꾸고 싶어요" (카드 변경)
👤 고객
"카드를 바꿔서 다시 결제하고 싶어요."
📕 지금 (불편함) 결제금액 한도가 정해져 있어서…
① 예약금액을 100→200으로 올림
② 고객 재결제 받음
③ 다시 예약금액을 200→100으로 내림
· 그 사이 고객이 "내 예약" 화면에서 잘못된 금액(200만원!) 봄
· "왜 갑자기 비싸졌어요?" CS 폭주
→
📗 앞으로 (편리) 예약금액 그대로 두고 결제수단만 변경.
① "결제수단 변경" 버튼 클릭
② 새 결제링크 SMS 자동 발송
③ 고객 재결제 완료 → 기존 결제 자동 취소
· 고객 "내 예약" 금액 변동 없음
· 결제 공백 없음
사례 ③ — "쿠폰 적용된 예약인데 행사를 옮겨야 해요"
👤 고객
"출발일을 7일에서 14일로 바꾸고 싶어요."
📕 지금 (불편함) ① 기존 예약 취소완료 처리
② 새 예약 생성
③ 쿠폰은 재발급 어려워서 운영자가 직접 계산해서 "추가할인"으로 수동 입력
· 취소·재예약으로 보여서 취소율 통계 왜곡
· 쿠폰 금액 계산 실수 위험
→
📗 앞으로 (편리) "행사 이동" 버튼 한 번이면 끝.
① 옮길 행사 검색·선택
② 금액 자동 재계산 (상품가·특가·쿠폰 다)
③ 가계부에 변경 이력 자동 기록
· 취소·재예약 흔적 없음
· 쿠폰 수동 계산 X
· 출발전환율 통계 정상
사례 ④ — "어드민에서 본 인원수와 파트너스에서 본 인원수가 달라요"
👤 영업실 담당자
"이 예약, 어드민에서는 0명인데 파트너스에서는 3명으로 보여요. 어느 게 맞는 거예요?"
📕 지금 (불편함) 취소완료 예약의 인원수가 취소 경로에 따라 다르게 표시
· 어드민 취소 → 0명
· 파트너스 취소 → 마지막 수정값
· 정산 데이터 신뢰도 ↓
· 추가 확인 작업 발생
→
📗 앞으로 (편리) 화면별로 표시 기준 통일
· 목록 = 취소완료면 0명
· 엑셀 = 취소완료면 원래 인원 표시
· 어드민↔파트너스 데이터 일치
· 정산·리포트 신뢰도 회복

3 같은 예약, 지금 vs 앞으로 어떻게 보일까요?

방금 본 김여행님 예약을 현재 시스템 / 신규 시스템에서 어떻게 저장하는지 비교해볼게요.

항목 📕 지금 📗 앞으로
예약 단위 예약 1건 = 행 여러 개에 흩어져 저장 예약 1건 = 가계부 1권
금액 변동 추적 최신 금액만 보임 (덮어쓰기)
"왜 이 금액이지?" 추적 어려움		 시간 순으로 모든 변동이 줄줄이 남음
"4/27 9시에 누가 얼마 입금" 다 보임
분할 결제 (2명 나눠 결제) 예약을 2건으로 쪼개야 함 예약 1건에 결제 행만 2줄 추가
인원별 금액 합쳐진 총액만 보임 "이 분만 얼마 받았는지" 인원별로 보임
취소위약금 결제 시스템에서 별도 관리 (이중관리) 가계부에 "취소위약금" 한 줄로 추가
변경 이력 메모에 텍스트로만 남기는 경우 많음 모든 변경이 자동으로 가계부에 기록

4 운영자가 마주칠 화면 변화 (요약)

예약 상세 화면에서 새로 보이는 것

  • "기본탭" — 평소 보던 정보 (예약자·상품·금액·결제)
  • "원장탭" — 가계부 펼쳐보기 (CS 응대·정산 검증할 때 사용)
    • 예약금액 관리 (상품가/할인/쿠폰/조정)
    • 결제금액 관리 (결제/환불)
    • 정산 관리 (수수료/대금이전)
    • 전체 원장 (시계열 + 주체별·기간 필터)
  • 주체별 잔액 카드 — 고객 🙋 / 채널사 🔗 / 플랫폼 🏢 / 여행사 🚩 각각 얼마씩 들어왔고 나갔는지 한눈에
  • "+금액 추가" / "−금액 차감" 버튼 — 금액 직접 수정은 못 하고, 항상 가계부에 한 줄 추가하는 방식 (실수 방지)

5 핵심 변화 5줄 요약

1
예약 1건 = 가계부 1권. 모든 돈의 흐름이 시간 순으로 한 줄씩 기록돼요.
2
결제를 두 명이 나눠서 해도 예약을 쪼갤 필요 없어요.
3
결제수단 바꿀 때 예약금액을 임시로 올렸다 내렸다 할 필요 없어요.
4
행사 이동·쿠폰 변경 시 운영자가 직접 계산하지 않아도 자동 처리돼요.
5
취소완료 예약의 인원·금액 표시가 어드민/파트너스 다르게 보이지 않아요.
