메뉴 구성 비교 — PB 콘텐츠 관리

A: 현재 트리 · B: 플랫 3-row · C: 하이브리드 단일 row + 그룹 구분. 같은 11개 게시판을 3가지 방식으로 표현.
A 트리 (마스터-디테일, 현재 상태)
상품정보 + 필수공통이 primary. 선택된 상품정보에 따라 관련 기본정보가 ↳ 아래에 동적으로 노출됨.
Primary
📦 상품 정보 🌟 필수 공통
Secondary (관련 기본정보, 동적)
🗂 관련 기본정보
예: 항공권 선택 시 → 🛫 항공사 · 🌏 국가 · 📍 여행지 노출 / 보험·필수공통 선택 시 → secondary 숨김
👍 장점
  • 상품정보 ↔ 기본정보 관계 시각적으로 명확
  • 공간 효율 — 관련 있는 것만 보임
  • 운영 멘탈모델 그대로 (어디서 끌고 오는지 한눈에)
👎 단점
  • 2단계 인터랙션 필요 (먼저 부모 선택)
  • 기본정보 직접 진입 시 "내 부모 뭐지?" 사고 단계
  • 전체 게시판 한눈에 안 보임
B 플랫 3-row (그룹별 줄바꿈) ✨ 추천
3그룹 (상품정보 / 기본정보 / 필수공통)을 각자 한 줄씩. 11개 게시판이 항상 다 보이고 직접 클릭 가능.
📦 상품 정보 🗂 기본 정보 🌟 필수 공통
관계는 운영 가이드 / 등록 화면 안내문에서 설명. 메뉴는 순수 네비게이션.
👍 장점
  • 모든 게시판 1-click 직접 접근
  • 인지 부담 최소 (학습 비용 ↓)
  • 그룹 구분도 컬러 칩으로 명확
  • 매일 쓰는 어드민 운영 패턴에 적합
👎 단점
  • 3행 차지 (수직 공간 ↑)
  • 상품 ↔ 기본 관계는 직접 노출 안 됨 (가이드 필요)
C 하이브리드 단일 row + 그룹 구분
한 줄에 모든 게시판 + 그룹 칩으로 구분. 화면 좁아지면 자동 wrap.
📦 상품정보 🗂 기본정보 🌟 필수
화면 좁으면 가로 스크롤 또는 wrap. 그룹 칩 텍스트 축약 가능.
👍 장점
  • 한 줄에 모든 것 — 시각적 컴팩트
  • 그룹 구분은 유지
  • 전체 게시판 동시 노출
👎 단점
  • 가로폭 부담 큼 (좁은 모니터에서 wrap/스크롤)
  • 탭 텍스트 축약 필요 (스팟·체험 → 스팟)
  • 그룹 칩과 탭 사이 시각적 위계 약함
🎯 추천: B (플랫 3-row)
TRP 어드민은 운영자가 매일 들어와서 11개 게시판을 자유롭게 오가는 도구입니다.

→ 1-click 직접 접근이 가장 중요. 트리(A)는 멋있지만 "부모 먼저 선택"이 매번 부담.
→ 운영자는 이미 11개 게시판 관계를 알고 있고, 관계 설명은 등록 화면 안내문에서 해도 충분.
→ 3-row지만 height는 그렇게 크지 않음 (각 row 38px ≈ 총 114px). 페이지 헤더보다 작음.
