2026-05-29 회의 핵심 결정 사항 (Area 1 관련)

  • 구성 요소 4종 — 항공권 · 숙박권 · 투어/티켓 · 보험
  • 등록 방식 2종 — 인디비(API 연동) / 수동
  • 항공 인디비 = 누아 API, 숙박 인디비 = TMG
  • 투어/티켓은 수기 등록만 지원, 단 투어 그룹(=일정표) 컨셉 도입
  • 누아 항공 동기화: 매일 일별 갱신 (60일 범위 · 조건당 60콜 = 안전)
  • TMG 숙박: 고정요금+고정재고 / 고정요금+실시간재고 / 실시간+실시간 3 rateType
  • TMG는 웹훅으로 변경 푸시 → 별도 정기 배치 불필요
  • 자동 조합 대상 여부 = 각 자원의 ON/OFF 플래그로만 관리
  • 노출 컷 = 마진 양수 + 경쟁가 이내 + 미노출 처리 안 함
  • 유사도 4-tier 자동 노출 컷 룰 폐기 (2026-05-20) → 매핑+가격 정리 뷰만

📌 rateType별 처리
  • STATIC — 고정요금 + 고정재고. 확정된 것만 전달받음. 별도 갱신 불필요.
  • ALM-DYNAMIC — 고정요금 + 실시간재고. checkAvailability로 재고 확인 (오늘+7일~+90일).
  • DYNAMIC — 실시간요금 + 실시간재고. 매일 새벽 분산 batch + 낮 PDP 트리거 분산 처리.
⚠️ 변경된 정책
TMG가 변경사항을 웹훅으로 푸시하므로, 별도 일별 배치는 실시간 요금표만 대상으로 새벽 1회. 가지고 있는 데이터가 항상 최신.
