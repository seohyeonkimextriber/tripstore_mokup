02

핵심 의사결정 요약

한 화면에 보는 5가지 베이스 룰

1 다 만들고 탈락
모든 가능한 조합을 일단 다 생성하고, 게이트 통과 못 한 것만 미노출 / Reject Pool로.
"가격/경쟁력은 다음 단계로"
2 항공 발권 = 예약 완료
베이스 룰: 항공 발권 완료 시점 = 예약 완료. 숙소는 후속 처리.
고객 화면은 항공권 기준.
3 즉시확정관
자동×자동 조합 = 결제 즉시 확정.
11:30까지 무료 취소 가능. (이전 30분 홀드 정책에서 변경)
4 콘텐츠 참조 방식
카피·고정 X → 참조(불러오기). 한 콘텐츠에 항목 N개 묶기.
수정 시 연결된 모든 상품에 자동 반영.
5 사유 단순화
8개 사유 → 3개로 축소. 영구 제외 폐기.
학습 기반 사유는 Phase 2 보류.
6 11:30~12:00 점검
자정 환율 변동 대비 시스템 리프레시 시간.
이 시간 예약 = 홀드 후 12시 자동 확정.

A 자동 자동 즉시확정관 결제 즉시 항공 발권 + 숙소 confirm 자동 진행. 11:30까지 무료 취소.
B 자동 수동 파트너스 확인 항공 즉시 발권 + 숙소는 파트너스 관리자 수동 처리.
C 수동 자동 파트너스 확인 숙소 자동 confirm + 항공은 파트너스 관리자 수동 처리.
D 수동 수동 파트너스 확인 항공·숙소 모두 파트너스 관리자 수동 처리.
💡 케이스 분기 — 사용자 입장
모든 케이스에서 항공 발권 완료 = 예약 완료. 숙소는 후속 처리.
단, A 케이스만 즉시확정관 (취소 페널티 적은 무료 취소 시간 보장).
B/C/D는 파트너스 응대 시간 발생 — 알림톡으로 진행 상태 안내.
⚙ 케이스별 화면 시연
예약 상세 v3 (reservation-detail-v3.html) 화면에서 케이스 셀렉터 칩으로 직접 토글:
✅ 정상 6단계 시뮬 / ❌ 항공·숙박 실패 케이스 / ✋ B·C·D 수동 케이스 → 진행 바 색·라벨 자동 변경
