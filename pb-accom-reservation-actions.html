❌ TMG 가용 불가 — UNAVAILABLE

reserveBooking 응답: UNAVAILABLE

TMG측에서 해당 객실 예약이 불가합니다. (재고 사라짐 / 호텔측 차단 / 기타)

처리 가이드
① 운영팀 자동 알림 발송됨
② 대체 숙소 조회로 다른 옵션 검색
③ 고객에게 안내 → 동의 시 대체 자원으로 예약

❌ 호텔측 거부 — Canceled

confirmBooking 응답: Canceled

TMG가 reserveBooking까지는 받았으나, 최종 confirmBooking 단계에서 호텔측이 거부했습니다.

처리 가이드
① 운영팀 자동 알림 발송됨
② 대체 숙소 협의 또는 고객 환불 처리
③ 호텔측 사유 확인 후 운영 판단

❌ 비정상 상태 — PENDING

retrieveBooking 응답: PENDING

TMG 측 상태가 비정상으로 멈춰있습니다. (시한 만료 직전 처리 누락 등)

처리 가이드
① 실패로 처리 (PENDING은 실패 케이스로 분류)
② 운영팀 자동 알림 발송됨
③ 재예약 필요 — [재예약 시도] 또는 대체 숙소 조회

⏰ 홀드 시한 초과 — confirmBefore 만료

TMG가 홀드를 자동 해제했습니다.

계약 요금 12h / 다이나믹 ~30분 시한 내 confirmBooking 호출 못 함.

처리 가이드
① 어드민 [예약 만료] 상태 표시
② [재예약 시도] 자동 호출 — checkAvailability → reserveBooking → confirmBooking 일괄
③ 재고/가격 변동 시 운영팀 수동 처리
