TMG 숙소 요금표 관리
요금타입별로 PB 숙박권 생성 방식이 달라집니다. 목록의 타입 배지로 구분됩니다.
📋
TMG 요금표는 요금·재고 제공 방식에 따라 3가지 타입으로 자동 분류됩니다 (TMG rateType 기반).
· 고정요금 TMG 확정값 그대로 — PB 숙박권 등록 시 별도 조회 불필요
· 재고변동요금 요금 고정 / 재고는 실시간 — PB 숙박권 등록 후 재고 동기화
· 다이나믹요금 요금·재고 모두 실시간 — PB 숙박권 등록 후 동기화
→ 이 화면은 TMG 요금표 메타 모니터링 + PB 숙박권 생성 진입점. 재고/요금 조회 상태는 PB 숙박권 관리 화면에서 확인.
🎯 자동생성 대상 — PB 숙박권이 생성된 행은 토글로 자동 PB 상품 생성 포함 여부를 제어합니다. ON인 숙박권만 새벽 배치에서 자동 PB 상품 조합에 참여합니다. 미생성 행은 토글 비활성.

→
② 상세 진입오늘 refresh 안 됐으면 → checkAvail 호출 + 저장값 갱신 (낮시간 refresh)
→
③ 노출 갱신변동 있으면 즉시 PDP 반영
→
④ 결제 직전 Gate 1재고 0 → 마감 안내
→
⑤ 결제 직전 Gate 2가격 변동(하락·초과 동일) → 안내 + 재결제
